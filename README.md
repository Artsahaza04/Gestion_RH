# 💼 Gestion RH – PHP / MySQL

Projet de gestion des ressources humaines développé en PHP.

## 🔐 Fonctionnalités
- Authentification Admin / RH
- CRUD Employés
- CRUD Services
- Gestion des congés
- Dashboard RH
- Recherche & filtres

## 🛠️ Technologies
- PHP 8
- MySQL
- Bootstrap 5
- PDO
- Git / GitHub

## 🚀 Installation
1. Cloner le projet
2. Importer la base de données
3. Configurer `config/db.php`
4. Lancer avec XAMPP
